### Задача 1.2: Сумма двух последних цифр

#### Текст задачи

Дана сигнатура метода: `public int sumLastNums(int x);`
Необходимо реализовать метод так, чтобы он возвращал результат сложения двух последних знаков числа `x`, предполагая, что знаков в числе не менее двух.
Подсказки: `int x = 123 % 10;` // x будет иметь значение 3; `int y = 123 / 10;` // y будет иметь значение 12.
Пример: `x = 4568`, результат: `14`.

#### Алгоритм решения

1. Взять модуль числа `x`.
2. Получить последнюю цифру: `x % 10`.
3. Получить предпоследнюю цифру: `(x / 10) % 10`.
4. Вернуть сумму этих двух цифр.

#### Код метода

```java
public int sumLastNums(int x) {
    x = Math.abs(x);
    int last = x % 10;
    int prev = (x / 10) % 10;
    return last + prev;
}
```

### Задача 1.3: Букву в число

```java
public int charToNum(char x) {
```

Пример 1: `a = 3`, `b = 6`, результат: `true`.
Пример 2: `a = 2`, `b = 15`, результат: `false`.

#### Алгоритм решения

Сначала проверка на ноль (чтобы избежать деления на ноль). Затем с помощью оператора остатка от деления `%` проверяются условия `a % b == 0` или `b % a == 0`.

#### Код метода

```java
public boolean isDivisor(int a, int b) {
    if (a == 0 || b == 0) {
        return false;
    }
    return a % b == 0 || b % a == 0;
}
```

### Задача 2.8: Возраст

#### Текст задачи

Дана сигнатура метода: `public String age(int x);`
Необходимо реализовать метод так, чтобы он возвращал строку, в которой сначала будет число `x`, а затем одно из слов: `год`, `года`, `лет`.
Слово «год» — если число заканчивается на 1, кроме 11.
Слово «года» — если на 2, 3 или 4, кроме 12, 13, 14.
Слово «лет» — во всех остальных случаях.

Пример 1: `x = 5`, результат: `"5 лет"`.
Пример 2: `x = 31`, результат: `"31 год"`.
Пример 3: `x = 44`, результат: `"44 года"`.

#### Алгоритм решения

Получается последняя цифра (`x % 10`) и последние две (`x % 100`). Если 11–14 — «лет». Иначе если 1 — «год». Иначе если 2, 3 или 4 — «года». Иначе — «лет».

#### Код метода

```java
public String age(int x) {
    int lastTwo = x % 100;
    int lastOne = x % 10;

    if (lastTwo >= 11 && lastTwo <= 14) {
        return x + " лет";
    } else if (lastOne == 1) {
        return x + " год";
    } else if (lastOne >= 2 && lastOne <= 4) {
        return x + " года";
    } else {
        return x + " лет";
    }
}
```

Пример: `x = 12567`, результат: `5`.

#### Алгоритм решения

Берётся модуль числа. Если `x == 0`, возвращается `1`. В цикле `while` число делится на 10 и счётчик увеличивается на 1.

#### Код метода

```java
public int numLen(long x) {

        return 1;

    int count = 0;
    while (x > 0) {
        x /= 10;
        count++;
    }
    return count;
}
```

#### Текст задачи

Дана сигнатура метода: `public int[] add(int[] arr, int x, int pos);`
Необходимо реализовать метод так, чтобы он возвращал новый массив, в котором в позицию `pos` вставлено значение `x`.
Пример: `arr = [1, 2, 3, 4, 5]`, `x = 9`, `pos = 3`, результат: `[1, 2, 3, 9, 4, 5]`.

#### Алгоритм решения

Создаётся массив размером `arr.length + 1`. Копируются элементы до `pos`, вставляется `x`, копируются оставшиеся со сдвигом вправо.

#### Код метода

```java
public int[] add(int[] arr, int x, int pos) {
    int[] res = new int[arr.length + 1];
    for (int i = 0; i < pos; i++) {
        res[i] = arr[i];
    }
    res[pos] = x;
    for (int i = pos; i < arr.length; i++) {
        res[i + 1] = arr[i];
    }
    return res;
}
```

### Задача 4.5: Добавление массива в массив

#### Текст задачи

Необходимо реализовать метод так, чтобы он возвращал новый массив, в котором в позицию `pos` вставлен массив `ins`.
Пример: `arr = [1, 2, 3, 4, 5]`, `ins = [7, 8, 9]`, `pos = 3`, результат: `[1, 2, 3, 7, 8, 9, 4, 5]`.

#### Алгоритм решения

Создаётся массив размером `arr.length + ins.length`. Копируются элементы `arr` до `pos`, затем `ins`, затем оставшиеся элементы `arr`.

#### Код метода

```java
public int[] add(int[] arr, int[] ins, int pos) {
    int[] res = new int[arr.length + ins.length];
    for (int i = 0; i < pos; i++) {
        res[i] = arr[i];
    }
    for (int i = 0; i < ins.length; i++) {
        res[pos + i] = ins[i];
    }
    for (int i = pos; i < arr.length; i++) {
        res[ins.length + i] = arr[i];
    }
    return res;
}
```

Пример: `arr = [1, 2, 3, 4, 5]`, результат: `arr = [5, 4, 3, 2, 1]`.

#### Алгоритм решения

Проходим по первой половине массива. Меняем местами элементы `i` и `arr.length - 1 - i`.

#### Код метода

```java
public void reverse(int[] arr) {
    for (int i = 0; i < arr.length / 2; i++) {
        int temp = arr[i];
        arr[i] = arr[arr.length - 1 - i];
        arr[arr.length - 1 - i] = temp;
    }
}
```

Необходимо реализовать метод так, чтобы он возвращал массив индексов всех вхождений числа `x` в массив `arr`.
Пример: `arr = [1, 2, 3, 8, 2, 2, 9]`, `x = 2`, результат: `[1, 4, 5]`.

#### Алгоритм решения

Считаем количество вхождений `x`. Создаём массив нужного размера. Записываем индексы во втором проходе.

#### Код метода

```java
public int[] findAll(int[] arr, int x) {
    int count = 0;
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == x) {
            count++;
        }
    }
    int[] res = new int[count];
    int index = 0;
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == x) {
            res[index] = i;
            index++;
        }
    }
    return res;
}
```
